# Интеллектуальная система управления ресурсами молочного производства

Учебный статический веб-прототип по лабораторной работе №11. Проект повторяет формат примера Agro-UAV: отдельные HTML-страницы по этапам, общие CSS/JS и интерактивные демонстрации на Canvas.

## Запуск локально
Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в VS Code.

## Развёртывание на Vercel
1. Создайте новый репозиторий GitHub.
2. Загрузите в репозиторий все файлы и папки проекта (index.html, stage*.html, style.css, app.js, vercel.json, README.md).
3. На Vercel выберите Add New → Project и импортируйте репозиторий.
4. Framework Preset: Other.
5. Build Command и Output Directory оставьте пустыми/по умолчанию; Root Directory — корень репозитория.
6. Нажмите Deploy.

## Важно
Это фронтенд-демонстрация на синтетических данных. Значения метрик в `results.html` являются иллюстративными. Для полноценного научного эксперимента нужно отдельно подготовить датасет и обучить настоящие модели ML/LSTM. Страница виртуального цеха является настольной 2D-симуляцией, а не полноценной VR-сценой.

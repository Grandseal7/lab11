Прогнозирование временного ряда с LSTM

Демонстрация принципа нейросетевого прогноза: модель учитывает последовательность предыдущих измерений, а не только текущее значение.

60

Порядок обучения

  1. Формирование временных окон без утечки целевых значений между выборками.
  2. Масштабирование признаков по обучающей части.
  3. Обучение LSTM с контролем ошибки на валидации.
  4. Ранняя остановка при отсутствии улучшения.
  5. Оценка на том же тестовом периоде, что и ML-модели.
Интерактивная страница иллюстрирует работу временного прогноза на синтетическом ряду. Это не запуск обученной PyTorch-модели в браузере.
